隐私政策

生效日期：2026-11-22

适用范围：蛋糕卷 CakeRoll（Windows 桌面版）

1. 概述

蛋糕卷是一款本地优先的笔记应用。你的笔记、附件和音频默认保存在本机，不需要注册账号，开发者也没有接收这些内容的服务器。

本政策说明应用会保存什么、在什么情况下联网、麦克风等权限用于什么，以及你可以怎样删除自己的数据。使用蛋糕卷即表示你了解本政策。

2. 数据保存在哪里

  • 默认保存在 %LOCALAPPDATA%\CakeRoll，包括数据库 cakeroll.db、笔记附件与音频文件。
  • 卸载应用通常不会自动删除该目录中的笔记；如需彻底清除，请手动删除该目录，或先导出备份再删除。

3. 我们不会收集什么

蛋糕卷没有账号体系，也不接入统计、广告、崩溃上报或用户画像 SDK。应用不会收集你的姓名、手机号、邮箱、身份证号、位置、通讯录、设备标识或使用行为，也不会在后台把本地内容上传给开发者。

应用只在你主动使用相应功能时联网，且连接对象由你决定，详见下一节。

4. 联网功能与触发条件

局域网同步（默认关闭）

当你在设置里开启同步服务后，应用会在本机启动一个 HTTP 服务，并显示二维码与网址供同一局域网内的设备连接。配对需要令牌或审批，数据只在你的设备之间传输，不经过开发者服务器。不方便扫码的设备，也可以直接填写局域网内另一台设备的网址来同步，请求只发往那台设备。你可以随时关闭该服务。

MCP 接入（默认关闭）

开启 MCP 后，应用会提供本机或局域网地址与 Bearer 令牌，供 Claude、Cursor、Qoder 等支持 MCP 的客户端访问。每个写入请求都会在应用内弹出审批，你可以拒绝。服务地址、令牌与开关状态均保存在本地，可随时关闭或重置。

内置资源

示例笔记、示例曲目、小精灵形象与配音随应用提供，读取时不需要联网。

5. 配音、提醒与通知

小精灵的配音随应用提供，读取时不联网；计划提醒使用本地通知。这些功能不依赖开发者的推送服务器，也不会把提醒内容发送到外部。

6. Microsoft Store 与可选换装

Windows 版通过 Microsoft Store 分发。应用与全部功能本身不需要购买，小精灵也能完整使用；换装加载项（CakeRollPetUnlock）只是可选外观。如果你选择购买，支付流程由 Microsoft 处理，蛋糕卷不会接触你的银行卡号、账单地址或账户密码。

应用只会向系统查询该加载项是否已激活，以决定是否显示额外换装。购买记录与支付信息由 Microsoft 按其隐私声明管理。

7. 你自行接入的第三方客户端

如果你通过 MCP 让第三方 AI 客户端读写笔记，这些客户端及其背后的服务商可能按其自身规则处理数据。蛋糕卷无法控制第三方的行为，请在接入前确认你信任该客户端，并只授予必要的访问范围。

8. 数据的导出与删除

  • 你可以随时在应用内导出 .rollcake 文件，把笔记和相关文件打包备份。
  • 在应用内删除笔记后，该笔记会从列表移除；如需彻底清除，可删除数据目录。
  • 关闭局域网同步或 MCP 后，对应的网络服务立即停止监听。
  • 卸载应用不会自动删除 Windows 用户目录中的笔记，请按需备份或手动清理。

9. 儿童

蛋糕卷不面向儿童收集个人信息，也没有针对未成年人的数据采集行为。应用内的内容完全由使用者自己创建和管理。

10. 政策更新与联系

如果应用功能或数据处理方式发生变化，本政策会同步更新，并在本页标注新的生效日期。继续使用即表示你接受更新后的政策。
