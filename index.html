      Usage Guide

      Step 1: Create Command Task

      Fill in the command parameters in the creation page. You can set fixed parts, parameters, directory selections, and key-value inputs.

      Step 2: Edit Command

      Click the edit button on the note page to modify saved commands. Click the edit button on optional parameters to edit added parameters.

      Step 3: View Exported JSON

      After creating the command, the system will generate a structured JSON file. You can copy or download it directly.

      JSON Preview 
      {
  "command_tasks": [
    {
      "id": 0,
      "name": "dir",
      "parts": [
        {
          "Fixed": "dir"
        },
        {
          "Dir": {
            "key": "directory"
          }
        },
        {
          "Param": {
            "name": "mode",
            "options": [
              "/a",
              "/w",
              "/s"
            ]
          }
        }
      ],
      "is_blocking": false,
      "group": "Directory",
      "note": ""
    }
  ],
  "cmd_next_id": 1
}

      Step 4: Execute Commands

      Choose to execute commands in CMD or PowerShell. You can check "Keep Session" to maintain an interactive session after execution, or leave it unchecked to exit automatically. Click "Stop All" to terminate running commands and end the session.

      Step 5: Edit Templates

      Click the button below to jump to the template library. You can modify the JSON content and download the updated version.

      Go to Template Library →

      Step 6: Import File to CmdNote

      Import the downloaded JSON file into CmdNote to start using your command templates.

      Open CmdNote, click the import button, and select your JSON file to load all command templates.
